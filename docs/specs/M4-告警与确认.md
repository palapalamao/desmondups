## Goal

M4 告警与确认：全车队告警闭环处置页（SPA 路由 `#/ups/alarms`）。本项目首个写操作模块——守门引擎 fail-closed 是核心。

- REQ-M4-01 告警列表：授权站点内全部告警（跨单元聚合），含单元/站点/消息/相对时间/严重度/状态
- REQ-M4-02 筛选：站点/严重度/状态（活动/已确认）/单元关键字；深链参数化
- REQ-M4-03 确认操作：行内展开（备注必填）→ 提交守门 → 状态翻转
- REQ-M4-04 守门引擎：四路拒绝（不存在/已确认/空备注/越权）明示理由（gateAck 纯函数）
- REQ-M4-05 幂等：重复提交零副作用（守门拒绝保证）
- REQ-M4-06 状态机单向：已确认不可变更（applyAck 数据层拒绝）
- REQ-M4-07 审计发射：确认成功 push 审计事件（操作者/时刻/备注/告警引用，M6 消费）
- REQ-M4-08 导航衔接：M2 告警面板\"去处理 →\"链接（纯导航，M2 零写不破）；M1 统计徽标联动可选
- REQ-M4-09 权限留位：站点授权 ctx.allowedSites 走守门参数，Mock 放行为全站点
- REQ-M4-10 裁剪留痕：批量确认/撤销/规则配置 = 二期
