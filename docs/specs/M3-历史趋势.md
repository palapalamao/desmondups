## Goal

M3 历史趋势：单台 UPS 单元的全量 his 查询视图（SPA 路由 `#/ups/history/{id}`，M2 详情深链进入）。

- REQ-M3-01 深链与入口：`#/ups/history/{id}?metric=&span=`；M2 详情页"全量历史"按钮进入；M1 卡片不进（D-07）
- REQ-M3-02 指标多选：SOC / 负载 / 电池温度（his 点位 upsSocPct / upsLoadPct / upsBatteryTemp，points.xeto 已盘）；默认 SOC+负载
- REQ-M3-03 跨度预设档：1h / 24h / 7d / 30d；粒度随跨度自适应（段 2 定死规则）
- REQ-M3-04 事件叠加：upsInputFail（市电中断）/ upsTransferOk（切换成功）曲线上标记 + 图例（事故复盘锚点）
- REQ-M3-05 缺口显式：断讯时段留白 + 图例标注，禁止插值连线（R3）
- REQ-M3-06 口径标注：历史区标注 his 采集口径；参考值不混入历史曲线（R3）
- REQ-M3-07 返回上下文：返回 M2 详情保留状态（反向深链参数透传）
- REQ-M3-08 只读：纯查询零写入口（R2 天然，CI 可证）
- REQ-M3-09 裁剪留痕：多单元对比 / 自由起止 / 导出 = 二期，本模块不实现
