# dev/11 · 错误码全表（UPS-nnnn）

> 上游：FIN-Pod 方法论 P4（错误码必须在 DD 阶段一次定完；每行四列：码/HTTP/含义/处置建议）
> 编号空间与底座错误码前缀区分、不合并。当前接口面为 Axon + SPA（08-api §0），
> HTTP 列为 REST 预留语义，Axon 场景以 code 为准。
> **预留段是分配声明不是 TBD**：新增错误只能占用本表已预留段内的下一个空号，不得跳段、不得复用已废码。

## 1xxx 参数

| 码 | HTTP | 含义 | 处置建议 |
|---|---|---|---|
| UPS-1001 | 400 | 缺少必填参数 | 对照 08-api/Axon 签名补齐参数后重试 |
| UPS-1002 | 400 | 参数格式非法（Ref/时间/span 解析失败） | 检查参数格式：Ref 用 `id @库名`，时间 ISO 8601 带时区 |
| UPS-1003 | 400 | 分页/排序参数越界 | limit 不得超过上限；sort 字段须在白名单内 |

## 2xxx 权限（红线 R1）

| 码 | HTTP | 含义 | 处置建议 |
|---|---|---|---|
| UPS-2001 | 403 | 越权访问（站点超出 principal scope） | 联系管理员开通站点授权；系统已写审计，勿反复重试 |
| UPS-2002 | 401 | 未认证/会话失效 | 重新登录 FIN；若复现检查 pod 是否在「设置→扩展」启用 |

## 3xxx 核心算法

| 码 | HTTP | 含义 | 处置建议 |
|---|---|---|---|
| UPS-3001 | 422 | 聚合计算输入存在缺口（某单元无实测值） | 该单元按 gap 剔除并在响应标注，不整体失败；排查采集链路 |

## 4xxx 外部数据与映射

| 码 | HTTP | 含义 | 处置建议 |
|---|---|---|---|
| UPS-4001 | 502 | 连接器通讯异常 | 查连接器在线状态与点位新鲜度；恢复后 hisRead 回补 |
| UPS-4002 | 422 | 外部编码未映射 | 进未映射池不丢弃（mapping.xeto 约束 4）；补映射版本后按原始编码回溯重算 |
| UPS-4003 | 409 | 映射版本失效/生效期重叠 | 只新增带新生效期的版本，禁止修改历史映射（R5） |

## 5xxx 口径（提示级，HTTP 200）

| 码 | HTTP | 含义 | 处置建议 |
|---|---|---|---|
| UPS-5001 | 200 | 数据降级为参考值（stale） | 仅用于展示，不得充当实测参与计算；排查采集超时 |
| UPS-5002 | 200 | 缺口无数据（gap） | 禁止插值/默认值填补；查点位缺失原因 |

## 6xxx 红线与守门（R2/R5）

| 码 | HTTP | 含义 | 处置建议 |
|---|---|---|---|
| UPS-6001 | 200 | 守门否决（判决 rejected） | 查看 verdict.items 逐条整改；硬约束未过不得重提 |
| UPS-6002 | 400 | 写接口缺 Idempotency-Key | 客户端生成幂等键重发；键缓存 24h |
| UPS-6003 | 409 | 幂等键冲突（同键不同负载） | 用新键发起新操作；同键同负载直接返回首次结果 |
| UPS-6004 | 422 | 校验未过不可发布 | 按校验项修正配置后重新走守门流程 |

## 7xxx 工单 · 8xxx 资产 · 9xxx 调度与应急

**整段预留**（M4 告警工单 / M5 资产与配置 / 应急联动微流程启用时按段内顺序取号）。
预留段启用前，相关场景的错误一律归入 1xxx/4xxx/6xxx 既有码，不得抢号。

## 收敛与抛错约定

- 对外可见的校验/业务失败一律收敛为 `UpsError`（code/msg/detail/httpStatus），底层异常不得漏出（Fantom 侧 M5 起实现）
- 前端 fail-closed：加载失败渲染 fatal 并明示原因，不兜底不静默（已实现，boot catch）
- 判决类（6001）是 200：业务结果非错误，客户端按 verdict 分支处理
