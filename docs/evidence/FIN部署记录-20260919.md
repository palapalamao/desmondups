## 环境坑登记（本次新发现，3 条）

1. **本机 UAC 对管理员静默提权**（ConsentPromptBehaviorAdmin=0）：`-Verb RunAs` 不弹框，但 **`Start-Process -ArgumentList '-Command','...'` 的嵌套引号会被 PowerShell 破坏**（exit 1 且无输出）。**必须写成 .ps1 文件用 `-File` 执行**——同机已验证两次。
2. **非提权 shell 写 Program Files 必拒**：IsInRole(Administrator)=False 时 Copy-Item 直接 Access Denied，走 `-File` 提权脚本即可。
3. `fin.bat` 是 FIN 主机启动器（抢 var\vm.lock），不是 CLI——FIN 服务运行期间不能用它跑命令；对运行中 FIN 的操作用 8080 Web。
