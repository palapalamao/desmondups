## 2. 设计决策（段 2 新增，全部留痕）

| # | 决策点 | 结论 | 备选（否决） |
|---|---|---|---|
| D-M2-01 | 时效粒度 | **面板组级 ts**（batteryTs/loadTs/electronicsTs/envTs/transferTs）；一组点位视为同采集周期 | 点位级 ts（成本/收益不值，二期可细化） |
| D-M2-02 | 断讯单元详情页 | detail=null → 档案区照常（名称/站点/位置是档案非遥测），遥测面板整区不渲染 + 通讯中断明示 | 渲染最后已知值（否决：给过期数据续命，R3/Q11 同规） |
| D-M2-03 | 告警数据来源 | Mock=种子内嵌 alarms 数组（确定性）；Fin=FIN alarm 查询，severity 复用内核（Q3 同规） | 自建告警存储（违反零新增） |
| D-M2-04 | 参考值标记 | 预测类字段（预估备电/预测更换/风险项）统一 `reference:true + source 文案`，UI 挂"参考值"标 | 混入实测值不标注（违反 R3） |
| D-M2-05 | 页面时效聚合 | pageFreshness = 各组最差（gap > stale > ok），头部一眼可见 | 逐面板各自标注即可（备选，取更保守） |

## 3. 数据契约（demoSeed 扩展示意，段 3 实现；全部确定性，TC-08 扩展断言）

```jsonc
unit.detail = {
  battery:   { stringVoltage, impedance, impedanceBaseline, temperature, chargeCurrent, predictedReplacement, reference:true, source:"趋势外推" },
  load:      { kw, capacityKw, requiredMinutes },
  electronics:{ inverterVoltage, inverterFrequency, inverterThd, rectifierStatus, fanStatus, capacitorHealthPct },
  environment:{ ambientTempC, humidityPct, airQuality, waterDetected },
  transfer:  { switchStatus, bypassAvailable, lastTransferMs, lastTransferAt },
  predictions: [ { risk, label, value, reference:true, source } ],
  alarms:    [ { severity, message, time, ack } ],   // ack=状态展示字段，契约中无任何确认操作
  runtimeEstimate: { minutes, reference:true, source:"SOC×负载模型" },
  // 组级采集时间（D-M2-01）；断讯/缺口单元 detail=null（D-M2-02）
  ts: { battery, load, electronics, env, transfer }
}
```

- 状态枚举沿用 tags.xeto：rectifierStatus/fanStatus/switchStatus/airQuality ∈ {normal, warning, critical}（与原型 tag-* 样式对应）
- 适配器契约新增：`adapter.detail(id) → Promise<detail|null>`；Mock=读种子；Fin=fail-closed 桩（U-API-01 解锁后实现 upsUnitDetail()）
- 详情页轮询：unit 视图下同 10s 周期调 detail(id) 后 renderUnit（与 M1 轮询互不干扰）

## 4. 纯逻辑契约（落 upsCore，Node 可测）

| 函数 | 行为 |
|---|---|
| buildDetail(units, id) | 取单元详情；未找到/断讯 → null（fail-closed 不兜底） |
| pageFreshness(detail, now, period) | 各组 classifyFreshness 取最差：gap > stale > ok（D-M2-05） |

## 5. 告警区只读契约（R2 第 7 位落点）

- 模板不渲染任何确认/操作按钮（不渲染 ≠ 禁用）；段 3 走查断言 DOM 无 button 于告警面板
- detail 契约无写操作字段；scripts/check 扩展 r2 扫描 renderUnit 模板段无 ack 处理函数（段 3 执行）
