## 1. 配置域（Q1 钉死：阈值 MVP，站点维度）

| 键 | 含义 | 域 | 单位 | seed 默认值 |
|---|---|---|---|---|
| socLowPct | SOC 告警下限 | 5 ~ 50 | % | 20 |
| impedanceDevPct | 内阻基线偏差告警阈 | 5 ~ 50 | % | 15 |
| battTempHighC | 电池温度上限 | 30 ~ 60 | °C | 40 |

- 配置粒度 = **站点级**（适用该站全部单元）；单元级覆盖 = 二期留痕
- 档案/点位映射 = 只读展示（Q1 建议稿）；不新建点位（R2 零新增）

## 2. 守门校验契约（validateConfig 纯函数，fail-closed）

| 序 | 校验 | 拒绝理由（明示文案） |
|---|---|---|
| V1 | 键完整性：每个 def 键必须存在 | 配置项 X 缺失 |
| V2 | 数值类型：number 且 isFinite | X 不是有效数值 |
| V3 | 数值域：min ≤ v ≤ max | X 超出允许范围（min~max） |
| V4 | 站点授权 ctx.allowedSites | 站点越权：不在授权范围 |

- 返回 `{ ok:true }` 或 `{ ok:false, reasons:[...] }`——**全量收集**（非短路），一次提交给用户全部问题（A22 逐条明示）
- 校验不过 → 拒绝发布，versions/currentSeq/audit 零变更（fail-closed）

## 3. 版本结构 + 状态机（铁律 4：append-only，历史不可改）

```jsonc
version = {
  seq: 3,                        // 版本号，单调递增（1 = seed base）
  at: <ms>, by: "mock-operator",
  kind: "publish" | "rollback",  // 发布 | 回滚
  fromSeq: null | 1,             // 回滚来源版本（publish 为 null）
  summary: "变更 2 项：SOC 下限 20→15",
  values: { socLowPct: 15, ... } // 全量快照——存储即深拷贝，后续操作不可变
}
configStore = { defs, versions: [v1..vn], currentSeq } // effective = versions.find(currentSeq).values
```

- **publish(draft)**：validate → 通过则 push version(kind=publish, values=深拷贝(draft))，currentSeq=seq，发射审计
- **rollback(targetSeq)**：target 不存在 → 拒绝；通过则 push version(kind=rollback, fromSeq, values=深拷贝(target.values))——**红冲语义：历史版本零修改，旧版内容 100% 重放（A23）**
- 幂等重放：重复 rollback 同一版本 → 生成内容一致的新版本（seq 不同，内容可重放，不视为错误）

## 4. Mock 持久化决策（段 2 定死）

- configStore 存**内存 snapshot**（auditLog 同规）；seed 只含 configDefs+configBase（v1 快照）
- **不做 localStorage**：跨会话状态会破坏"种子确定性重建"叙事；页面重载回到 base 版本 = Mock 演示语义，UI 头部明示
- boot 初始化 `configStore = seed.configStore`（`{defs, versions:[v1], currentSeq:1}`）

## 5. 列表页交互（#/ups/config）

| 项 | 设计 |
|---|---|
| 头部 | 深链口径 + 操作者 mock-operator 明示 + "演示环境：重载回 base 版本"明示 |
| 生效区 | 当前生效值表（值+单位+域参考）+ 来源版本 seq + 版本历史按钮 |
| 草稿区 | 三项阈值编辑（number input，step 0.5）+ 校验发布按钮 + 放弃草稿 |
| 守门反馈 | 校验失败 → 逐条理由列表（红色），生效区不动（A25） |
| 版本历史 | 展开面板：seq/kind/时间/操作者/摘要/fromSeq；每行"回滚到此"按钮（已当前版本无按钮，UI 单向） |
| 审计 | publish/rollback 发射 `{seq,type:"config.publish"|"config.rollback",versionSeq,kind,summary,by,at,diff}`（M6 消费，A24） |
| r2 边界 | config 段写入口 handler = submitPublish/submitRollback；禁词表（pointWrite 等）均不命中；unit/详情段扫描不受影响 |
