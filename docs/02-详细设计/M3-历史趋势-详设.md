## 2. 设计决策（段 2 新增，全部留痕）

| # | 决策点 | 结论 | 备选（否决） |
|---|---|---|---|
| D-M3-01 | 跨度-粒度规则表 | 1h→10s原始(360点) / 24h→5min(288) / 7d→30min(336) / 30d→2h(360)；点数恒 ≤360 防 DOM 膨胀 | 自由粒度（否决：性能不可控） |
| D-M3-02 | 图形契约 | 双区 SVG：上区 220px（SOC 实线绿/负载 蓝），下区 120px（温度 琥珀，轴 15-45°C）；x 轴 5 档时间刻度共轴对齐 | 三指标共轴（否决：温度压扁 SOC 波动，Q1） |
| D-M3-03 | 历史留白口径 | **留白 = 采集空洞（该时段从未入库），与当前通讯状态解耦**——his 已入库即可查，断讯机的过去照常可查；只有从未采集的时段才留白（R3 精确口径，防误用 D-M2-02） | 断讯机全历史留白（否决：把 his 已入库数据也埋掉） |
| D-M3-04 | 事件派生规则（Mock） | prnd(u,day,\"fail\")<0.08 → 当天市电中断 1 次，时刻=prnd 派生小时；transferOk = inputFail + 2~8min；mode=battery 单元今日追加\"进行中\" inputFail（与 M1 状态自洽） | 均匀散布事件（否决：不像真实事故） |
| D-M3-05 | Mock 值派生 | hash(u.id+metric+slot)→mulberry PRND；值 = 日周期正弦(按 metric 调幅) + PRND 噪声 ±3；域：SOC 20-100 / 负载 15-90 / 温度 18-38 | 全正弦（否决：无噪声不像实测） |
| D-M3-06 | 空洞派生（Mock） | prnd(u,day,\"gap\")<0.06 → 当天连续 1-3h 空洞段（演示留白）；空洞内零数据点，曲线断开（禁插值 R3） | 无空洞（否决：留白场景不可演示，A15 无法验证） |
| D-M3-07 | 路由参数 | `#/ups/history/{id}?metrics=soc,load&span=24h`；metrics 缺省 soc,load；span 缺省 24h；非法值 fail-closed 收敛默认（不报错静默兜底——收敛即明示当前生效值） | 非法值报错页（否决：浏览器手改参数是正常探索，收敛更友好） |
| D-M3-08 | M2 回改点 | 电池/负载面板标题加\"全量历史 →\"链接（纯导航 # 跳转，非写入口，R2 不破）；带当前 metrics 上下文 | 入口放 M1 卡片（否决：D-07） |

## 3. 数据契约（adapter.history，段 3 实现）

```jsonc
adapter.history(id, { metrics:["soc","load","temp"], span:"24h" })
  → Promise<{
      series: { soc:[{t,v}], load:[{t,v}], temp:[{t,v}] },  // 已按粒度聚合，空洞段无点
      events: [ { type:"inputFail"|"transferOk", t } ],  // 跨度内事件，按时刻升序
      meta: { span, grainMin, anchorTs } }>
```
- Fin = hisRead 通道（08-api 总则；U-API-01 解锁后实现，fail-closed 桩先行）
- Mock = 运行时确定性派生（D-M3-05/06）；**seed.json 不膨胀**（78 万值不入库）
- 前端聚合与裁剪只在 Mock 侧；Fin 侧聚合由 hisRead 服务端做（粒度参数服务端语义）

## 4. 纯逻辑契约（落 upsCore，Node 可测）

| 函数 | 行为 |
|---|---|
| deriveHistory(unit, metric, span, anchorMs) | 确定性派生 [{t,v}]（D-M3-05/06；同锚同序列逐字节一致）；非法 metric/span → 空数组 |
| deriveEvents(unit, span, anchorMs) | 确定性事件表（D-M3-04）；battery 模式含进行中事件 |
| spanSpec(span) | 跨度规格 {grainMs, slots}（D-M3-01 规则表） |
| splitGaps(points, maxGapMs) | 空洞切分：相邻点距 > 2×粒度 → 分段（禁插值的渲染依据） |
| timeTicks(anchorMs, span) | x 轴 5 档刻度 {t,label}（格式化 yyyy-MM-dd HH:mm，本地时区） |

## 5. 渲染契约

- 双区 SVG 由 splitGaps 分段渲染，每段独立 polyline（空洞处断开可见）
- 事件锚点：上区竖虚线（inputFail 红 / transferOk 蓝）+ 下方事件条（时刻+类型+\"进行中\"标记）
- 图例：SOC/负载/温度/事件两色/**缺口留白（斜纹块）**——A15 图例要求
- 头部：返回详情（history.back）+ 单元档案条（同 M2 头部档案）+ 生效参数明示（收敛值展示，D-M3-07）
- 断讯/缺口机：**历史照常可查**（D-M3-03），头部仅标当前通讯状态，不阻断历史
