## 1. 查询契约（queryAudit 纯函数，Node 可测）

```js
queryAudit(events, f, now) → rows  // seq 倒序（新的在前）
f = { type, by, since, q }
```

| 筛选项 | 语义 | 收敛规则 |
|---|---|---|
| type | 精确匹配事件 type | 非法值 → 按空处理（不报错，徽标不高亮，同 M3 生效值明示） |
| by | 精确匹配操作者 | 动态下拉（collectOperators 去重升序） |
| since | all/1h/24h/7d 相对档 | 非法值 → all；锚点 now 参数注入（确定性可测） |
| q | 关键字：note/summary/message 子串（大小写不敏感） | 空 = 不过滤 |

- **空结果 → 空数组**：UI 明示"当前筛选无审计记录"（R3 不造假不兜底）
- 事件源 = auditLog（M4/M5 已发射，字段契约不重开）；M6 零写零发射

## 2. 类型元数据（Q5 钉死，三类）

| type | 中文标签 | 徽标色 | 明细字段展示 |
|---|---|---|---|
| alarm.ack | 告警确认 | tag-critical（红） | 告警消息/备注/单元/站点/严重度 |
| config.publish | 配置发布 | tag-normal（蓝） | 变更摘要/版本号 |
| config.rollback | 配置回滚 | tag-warning（黄） | 回滚来源/版本号 |

- 计数徽标 = 全量（未筛选）按 type 计数；激活高亮同 M1/M4 语言
- 明细展开：`showDetail=seq`（同时只展开一行）；字段缺失 → 该行不渲染（不造假）
