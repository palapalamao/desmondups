## 3. "不重复造轮子"纪律决定（初判）

| 能力 | 决定 | 理由 |
|---|---|---|
| 认证/授权/会话 | **复用**（FIN 内核） | 红线 1，不自带认证 |
| 点位模型/历史/告警存储 | **复用**（Folio + his + alarm 内核） | 平台内核能力 |
| UPS 领域语义（设备/电池串/模块/SOC/SOH…） | **全新**（`lib/ups/*.xeto`） | 领域特有，阶段 2 建模 |
| 车队监控 UI | **全新**（ext pod 前端，视觉沿用原型） | 原型仅为基线 |
| 配置下发守门 | **全新**（守门引擎，fail-closed） | 方法论要求独立成篇 |
| Modbus/BACnet 接入 UPS | **复用**（FIN 连接器） | 连接器已覆盖 |

## 4. 底座"不改写"边界（书面确认）

不直接写 Folio 内部表。任何看似需要改内核的需求，回退到扩展层重新设计。
